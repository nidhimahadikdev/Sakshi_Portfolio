SAKSHI NITIN MAHADIK — ACTRESS PORTFOLIO

HOW TO ADD PHOTOS
1. Keep index.html, style.css, script.js and README.txt together.
2. Put all photos in the single images folder.
3. Name the main/cover portrait photo1.png.
4. Name the remaining photos photo2.png through photo15.png.
5. Double-click index.html to open the portfolio in your browser.

GALLERY FEATURES
- Gallery photos appear in a clean, consistent grid without being cropped.
- Click or tap any gallery photo to open it large.
- Use the arrows or keyboard arrow keys to move between photos; press Escape to close.
- Missing photo files are automatically hidden, so no blank tiles appear.

IMPORTANT
- The images folder is included and ready for your photos.
- If your photos are JPG/JPEG, either convert them to PNG or change the image
  file extensions in index.html to match the actual file type. Renaming a file
  extension alone does not convert the image.
- The contact number is shown as +91 76209 73556.
- The website uses Google Fonts, so an internet connection is needed for those fonts.
